# 《奔月》参考资料索引

本目录只保存项目参考资料及其登记信息，不代表所有资料都已获准直接用于生成。

## 资料分区

| 分区 | 内容 | 使用原则 |
|---|---|---|
| [`official/`](official/) | 已取得原始文件的官方公开资料 | 优先用于锁定公开工程事实；仍不得声称复原未公开细节 |
| [`public-screenshots/`](public-screenshots/) | 公开传播中的信息图、媒体视频或社交平台截图 | 只作辅助理解和线索登记；使用前须核实来源及画面属性 |
| [`film-visuals/`](film-visuals/) | 电影、剧集等影视作品画面 | 只参考美术、摄影、表演和空间感；工程证据权重为零 |

## 统一约束

1. 官方原始资料的证据优先级高于转述截图、媒体动画和社交平台画面。
2. 试验件、悬吊装置、测量标志、地面线缆、保护包覆和画面字幕不得直接复制进正式飞行构型。
3. 公开资料没有展示的尺寸、内部布局、接口细节和材料工艺，继续按“未公开”处理。
4. 未标记为“可用于生成”的资料，仅可参与讨论、构型核对和后续溯源。
5. 影视作品画面不得用于证明航天器真实结构，也不得作为成片素材直接发布或复刻。
