## 官方核验后的功能边界

1. **舱内航天服不是日常工作服。** 它在座舱失压时提供个人压力与供氧保护，公开资料显示其由压力服、头盔、手套、压力调节／显示、应急供氧通风管路及生理监测／通信连接等组成。
2. **典型穿着阶段是发射、返回、变轨及交会对接等高风险阶段。** 航天员通常在座椅中受约束，并与飞船生命保障、通信和医学监测系统连接。
3. **正常入轨工作后换穿轻便舱内工作服。** 中国空间站公开画面中稳定出现蓝色长袖工作服；这是一种正常工作服装，不是舱内压力服。
4. **舱外服／登月服另属独立系统。** 舱内航天服不能替代飞天舱外服或登月服，蓝色工作服也不能用于失压或舱外环境。

完整来源、适用范围和梦舟边界见 [《中国公开资料核验》](中国公开资料核验.md)。

1. **梦舟关键阶段参考**：001—003 只为梦舟发射、返回和其他高风险阶段提供中国舱内压力服的功能／视觉家族依据；不得把神舟服逐件复制并宣称是梦舟定型服。
2. **梦舟正常巡航参考**：004 及官方空间站工作服照片可用于轻便、克制、便于失重活动的舱内工作服方向；具体剪裁、标识和颜色仍需形成《奔月》自己的未来任务版本。
3. **人员与任务区分**：本片三人可采用姓名牌、岗位识别和后期准确贴合的任务标识；AI 原图不得生成可读姓名、随机徽章或错误国旗。
4. **状态连续性**：同一场景必须按任务阶段锁定“压力服／工作服／登月服”之一，不能无程序依据地混穿或瞬间切换。
