## 可用与禁用边界

可借鉴：

- 锥形返回舱内部的压迫感和多人空间密度；
- 包覆式座椅、头枕、束缚带与人体姿态之间的画面关系；
- 圆形舱口/舷窗、侧壁设备区和座椅区的摄影组织；
- 戴手套操作、查阅手册、寻找控制件、应急饮水等人物行为；
- 冷绿色低照度、仪表自发光、窗外强光以及晃动镜头的紧张氛围；
- 失重进入、身体漂移和重新固定的动作设计线索。

禁止据此认定或直接照搬：

- 梦舟真实座椅数量、座椅角度、舱内容积和人员站位；
- 梦舟仪表板、按钮文字、控制逻辑、手柄位置和故障程序；
- 梦舟舱门、舷窗、管线、储物袋、通风管和内衬的真实布局；
- 影片中的中国文字、俄式/神舟式造型、演员服装徽章和道具标识；
- 原片构图、角色造型、字幕、水印或受版权保护的具体美术设计。

## 建议转化为项目设计语言

这批图不用于“照着做一个梦舟舱内”，而用于提炼五项独立原则：

1. **座椅是画面骨架**：人物大部分时间被固定在包覆式座椅内，镜头围绕头、手、膝和约束带组织。
2. **操作必须够得到**：关键控制区应落在受限坐姿的手臂可达范围，具体位置再依据梦舟功能设计重新建立。
3. **舱内要有方向混乱感**：通过相机滚转、窗外亮面和漂浮物表达失重，而不是把设备随意倒置。
4. **设备光服务剧情**：主照明低、局部按键和屏幕可读；紧急状态靠亮度和节奏变化，不复制影片色码。
5. **拥挤但不能杂乱**：软包、储物和管线需要分区固定，为三人返回舱保留清晰的操作面和逃生路径。
