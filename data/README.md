# data

本目录保存阶段1至阶段3的机器可读生产表。表头按规则包模板和Schema固定，不自行删减。

- `阶段1_资产统计表_V1.3.1.csv`：176项资产账本，158项有效、18项历史停用；
- `阶段1_资产变更映射表_V1.3.1.csv`：历史继承、语义扩展与30项新增资产；
- `阶段1_场景视图需求表_V1.3.1.csv`：17个场景资产组及58项母图／多视角登记；
- `阶段1_119镜资产调用映射_V1.3.1.csv`：119/119镜逐镜调用主表；
- `阶段1_场次资产需求映射_V1.3.1.csv`：15场聚合调用表；

- `阶段1_V1.3.1资产重分析与119镜映射.xlsx`：首次119镜映射工作簿，保留作本次层级重构前的历史快照。

## 资产分类与层级

- 人物资产：CHR、CRO、CST；服装和服装状态紧跟相应人物，父资产ID指向人物母资产；
- 场景资产：SCN及SCN-VIEW；层级固定为“场景资产组→母图→多视角”，多视角父资产ID指向对应母图；
- 道具资产：VEH、PRP，保留“载具／航天器”和“设备／道具”子类型；
- 特殊资产：ANM、LGT、VFX、REL、SYM；
- 声音资产：VOI、SND；VOI独立制作，SND作为随镜头视频同步生成的声音约束。

正式基础资产口径仍为176项；新增展开的58项场景母图／多视角属于视图登记项，因此工作簿“资产总表”共有234条登记记录。
