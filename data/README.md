# data

本目录保存阶段1至阶段3的机器可读生产表。表头按规则包模板和Schema固定，不自行删减。

## 当前状态

正式剧本已更新为V1.3（15场、100镜）。V1.3资产账本和100镜调用映射尚待阶段1重分析生成；在完成前，本目录没有可直接进入正式生产的现行映射表。

## V1.2历史数据

- `阶段1_资产统计表_V1.2.csv`：146项资产账本，128项有效、18项历史停用；
- `阶段1_资产变更映射表_V1.2.csv`：旧ID停用、升级和替代关系；
- `阶段1_场景视图需求表_V1.2.csv`：16个场景视图资产；
- `阶段1_114镜资产调用映射_V1.2.csv`：历史剧本V1.2逐镜调用主表；
- `阶段1_场次资产需求映射_V1.2.csv`：16场聚合调用表。

V1.0和V1.2数据只作历史追溯与资产复用比对，不作为V1.3镜头生产依据。视觉资产调用遵循“所见即所得”，不得由对白或解释文字触发当前画面不可见的视觉资产。
