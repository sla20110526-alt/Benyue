# 阶段2A｜《奔月》风格圣经短执行版 V1.1-DRAFT

状态：重入执行草案；首轮测试确认后升正式版。

## 1. 核心定位

中国首次载人登月的未来纪实推演。视觉接近真实任务纪录片和航天工程摄影，轻科幻只体现在合理的未来任务构型与界面，不做太空歌剧、豪华科幻驾驶舱或商业概念车美学。

## 2. 画面基调

- 克制、冷静、可信、任务优先；
- 真实摄影尺度，镜头有明确观察位置；
- 工程结构密度来自功能，不用无意义面板堆叠制造“未来感”；
- 白、灰、深灰为主，蓝色只用于扶手、识别件和低亮度界面；
- 材料以涂层金属、复合材料、隔热软包、织物储物袋、机械紧固件和耐磨地板为主；
- 保留适度使用痕迹，避免医院、游艇、商务舱和纯净展厅质感。

## 3. 梦舟V3.0

梦舟内部按三个视图资产设计：三座承力区、三座区域的环月工作状态、轴向对接通道。共享同一舱壁、座椅系统、材料、蓝色扶手、紧固件和暖中性任务灯。

三座承力区只显示返航承力关系；环月工作状态以其中一张任务席和共享前上方控制区为主体，相邻两张空座保留可识别边界，不增加第四个壁挂或站立工位；通道视图只显示舱门、转移路径与附近固定点。屏幕使用低亮度蓝灰任务界面占位，不直接生成可读文字。

## 4. 揽月与航天器

- 基于中国公开航天器资料、中国空间站和现役载人航天器的工程语言做功能性补全；
- 揽月外形保持已确认身份，完整构型、推进舱分离、着陆、上升、再对接和处置只改变任务状态；
- 对接轴、舱门、舷梯、着陆腿、喷口、样品固定与人员尺度必须相互成立；
- 不复刻未公开内部结构，不把艺术补全写成官方设计。

## 5. 月面

月面使用艺术化任务日光：硬主光从画面左前方进入，阴影向右后方延伸。原`225°／22°`只作为美术坐标，不表示2029年4月8日、11.97°N／3.21°W的真实自然照明。

天空纯黑，无大气散射、雾、风和体积光；月壤反射有限；阴影保持硬边与足够暗度。下降／起飞月尘贴地作弹道扩散，颗粒在低重力下回落，不形成空气涡流。国旗只因展开机构发生一次结构回弹，随后静止。

## 6. 飞控、测控与搜救

- 北京飞控强调多席位协作、任务主屏和克制状态照明，不做证券大厅或娱乐控制室；
- 佳木斯、喀什和VLBI席位必须可区分，天线和操作区只按公开工程特征表达；
- 搜救场景保持真实应急流程：先定位和安全检查，再开舱和医学处置；
- 群体不做统一复制脸，不用庆典式夸张情绪。

## 7. 再入与返回

返回舱需表现月地返回量级速度对应的高热流和等离子辉光；第一次再入、短暂跃出、第二次再入、通信衰减、伞降和气囊触地是连续状态链。辉光来自防热大底和流场，不做全舱均匀燃烧或奇幻火焰。

杨凛、陈砚、刘定槎沿用已确认人物身份，不重做脸。人物表现以训练有素、疲劳可控、动作简洁为主；不使用英雄海报式仰拍、夸张表情或时尚大片妆造。压力服、登月服和任务装备不改变人物身份。
