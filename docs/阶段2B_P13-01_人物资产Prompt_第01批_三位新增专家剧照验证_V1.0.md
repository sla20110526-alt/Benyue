## 1. 本批执行边界

- 本批只确认人物的脸、年龄感、性别提案、气质、真人感和基础职业造型方向。
- 不在本批锁定正式专家服装、采访动作、任务图卡、稳定音色或具体镜头构图。
- 三条 Prompt 必须分别生成，不得把三个人物合并在同一张图中。
- 建议执行顺序：何文澜、孙亦川为第一小批；顾青岚为第二小批。
- 生成图通过后，再分别制作人物基础多视图、正式专家服装和稳定音色。
- 三位人物均为虚构角色，不绑定现实专家、主持人、演员或公众人物肖像。
- 年龄、性别和面部骨相属于本轮创作补全，均须由主创确认后才能锁定。
