
阶段2A只做3-5个测试资产，不直接展开全量生产。建议测试链：

1. 杨凛人物剧照验证图。

3. 梦舟舱内三座布局母图与一个非母图方向视图。
4. 月面着陆与作业区母图与太阳方向测试。
5. 揽月登月舱外观或国旗装置关键材质测试。

## 3. 并行关系

- 人物基础、人物稳定音色、新闻支持人物可以在2A通过后分组并行。
- 梦舟舱内与揽月舱内可以并行，但对接通道与两侧舱门必须由同一空间关系切片统筹。
- 月面主空间、望宇登月服和任务设备可以并行起步，最终必须在月面空间总图中汇合。
- VFX不得先于相关载具、场景光影和物理来源资产确认。
