# 阶段1｜V1.3.1资产分类与父子层级规则

正式工作簿：`data/阶段1_V1.3.1资产分类层级与119镜映射.xlsx`

## 1. 五类资产

| 资产大类 | 纳入类型 | 说明 |
|---|---|---|
| 人物资产 | CHR、CRO、CST | 人物母资产、群体人物、服装与服装状态 |
| 场景资产 | SCN、SCN-VIEW | 场景资产组、母图与必需多视角 |
| 道具资产 | VEH、PRP | 航天器／载具与任务设备／道具 |
| 特殊资产 | ANM、LGT、VFX、REL、SYM | 动作链、光照、视觉特效、关系约束、后期图形与标识 |
| 声音资产 | VOI、SND | 独立稳定音色与随视频同步生成的声音约束 |

基础资产总数保持176项：人物25项、场景20项、道具36项、特殊65项、声音30项。

## 2. 人物层级

1. CHR人物母资产作为一级记录。
2. 对应CST服装和服装状态紧跟人物，作为二级记录。
3. 服装子资产的`父资产ID`必须指向对应CHR人物母资产。
4. CRO群体人物作为独立一级记录。
5. VOI稳定音色不混入人物表，统一登记在声音资产表。

## 3. 场景层级

场景统一采用三级结构：

1. 一级：SCN场景资产组；
2. 二级：SCN-VIEW场景母图；
3. 三级：SCN-VIEW场景多视角。

母图的`父资产ID`指向SCN场景资产组；每个多视角的`父资产ID`直接指向同一场景母图。生产顺序固定为先确认母图，再生成多视角和状态图。

V1.3.1共登记17个当前生产场景资产组、58项母图／多视角。连同3项历史停用场景，场景基础资产仍为20项；视图登记项不改变基础资产口径。

## 4. 总表口径

“资产总表”共有234条登记记录：

- 基础资产176项；
- 场景母图／多视角58项。

`基础资产标记`用于区分基础资产与视图登记；`有效标记`用于隔离历史停用项。119镜调用仍以原正式生产资产ID为依据，不因工作簿分类和显示顺序改变。

## 5. 声音边界

- VOI稳定音色独立制作、确认和登记；
- SND只登记声音设计约束，正式对白、无线电、设备声和任务通信随镜头视频同步生成；
- 月面外部无空气传播声；
- 全片不配乐。
