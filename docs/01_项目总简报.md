# 01｜《奔月》项目总简报

## 项目定位

《奔月》是一部使用 AI 制作的轻科幻纪实短片，以2029年4月8日为艺术化设定，推演中国航天员首次登陆月球的任务全过程。

成片不是官方任务预告，也不是技术说明片。片头明确“未来纪实推演”，人物、日期、口令、月面光照及未公开任务细节均为艺术化创作；航天器、任务架构、月面物理和声音逻辑以截至2026年7月公开工程资料为依据。

项目保留2029年4月8日和11.97°N、3.21°W设定，接受该日期／坐标与片中可见硬日光之间的天文偏差。月面画面采用为叙事可见性与跨镜连续性建立的艺术化任务日光，片头与片尾推演声明显式说明该偏差，不把画面光向表述为真实天文复原。

## 创作核心

- 不设置重大险情，张力来自分离、下降、触月、出舱、起飞、交会和返航等不可逆节点。
- 以岗位分工、操作接力、目光确认和熟练协助表现三人之间的程序性默契。
- 三名航天员同乘梦舟抵达月轨；对接后杨凛、陈砚转入揽月，刘定槎独留梦舟。三座满员—两张空座—三座重聚—三座返航构成贯穿全片的乘组关系视觉母题。
- 北京飞控、佳木斯、喀什、VLBI测轨网与搜救系统贯穿关键节点，任务不是航天员与AI独立完成的封闭行动。
- 全片采用三段直播：环月对接；落月—月面任务—再对接；离月返回—再入—东风回收。直播之间以深空画面、任务字幕、回放和时间压缩跨越长时段。
- 林知夏在飞控中心媒体区主持直播；飞行任务、乘员系统和月球地质三个专业方向专家只在关键事件之前、时间跨越处和事件之后解释，不覆盖任务关键口令。
- 第一脚只保留专业任务报告，不生造历史名句。
- 影像来源分为任务证据、直播解释和第三视角三套语言。月面相机部署前的第三视角必须标注“基于实时遥测的视觉重建”；部署后由同一台便携月面摄像机记录国旗、科研和月面起飞。

## 技术与美术边界

- 月面外部没有空气传播的发动机声、脚步声、尘土声、车轮声或旗帜飘动声。
- 月尘贴地放射状散开，按弹道回落，不形成地球式翻滚悬浮尘云。
- 六分之一重力降低重量，不消除质量和惯性。
- 月面为黑色天空、真空环境、深阴影和有限地表反射光，不做暖黄沙漠或大气霞光；月面主场景统一采用艺术化任务日光，MASTER左前入光、阴影右后，不随镜头翻转。该光向是生产坐标系，不代表2029年4月8日该坐标的真实太阳方位。
- 揽月采用公开的登月舱与推进舱口径，不套用阿波罗式上升级—下降级构型。
- 不虚构可读精确参数、未公开按钮布局、算法界面、口令和内部机构。

## 任务构型

- 梦舟由返回舱与无人服务舱组成。留守人员在返回舱内工作；服务舱负责推进、电源、热控、通信和消耗品支持，不设载人观察室。
- 揽月按着陆器与推进舱口径表达。推进舱负责降轨和主要制动；两名航天员乘着陆器完成落月、月面起飞和与梦舟再对接。
- 乘组与样品转回梦舟后，揽月进入受控处置；梦舟服务舱执行地月转移返回并在近地再入前分离，只有返回舱进入大气层。
- 小天是受限任务智能体，只执行传感器融合、走廊预测、候选区排序和异常提示。
- 近月和月面通信以佳木斯、喀什、阿根廷等深空地面站接力直达为主，由北京统一调度；关键操作安排在地面可见窗口，月球遮挡期由器上自主程序与预先装订指令承接。鹊桥二号位于24小时周期环月大椭圆冻结轨道并具备中继能力，但本片正面着陆任务不把它设为唯一或必需主链路；不采用鹊桥三号。
- 天链为地球同步轨道数据中继系统，本片不把它写成环月或月面主通信链路；地球近域返回阶段只保留可选辅助边界，不设置独立剧情。
- 本片主着陆场锁定东风着陆场；预计在黎明前后落地，以统一雷达、光学、终端红外和搜救画面逻辑。该选择具有公开载人飞船回收基础，但不表述为首次载人登月官方已公布方案。

## 声音锁定

- 人物稳定音色资产独立制作、确认并登记。
- 正式镜头中的对白、无线电、设备声和任务通信随视频同步生成。
- 月面外部的呼吸和无线电来自任务通信音轨，不是外部摄像机本地拾音。
- 全片不要配乐。
