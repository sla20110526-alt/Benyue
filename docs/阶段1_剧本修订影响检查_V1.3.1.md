## 2. 已修正的关键问题

### 2.1 乘组位置连续性

V1.3在对接前同时出现“揽月先期入轨”和“杨凛、陈砚已在揽月舱内”的矛盾。V1.3.1统一为：

1. 揽月以无人状态先期进入月球轨道。
2. 三名航天员同乘梦舟抵达月球轨道。
3. 对接期间三人全部在梦舟监控。
4. 对接和密封检查完成后，杨凛、陈砚转入揽月。
5. 刘定槎独留梦舟，两张座椅空置。
6. 月面起飞再对接后，三人重新回到梦舟。

由此建立“三座满员—两座空置—三座重聚—三座返航”的视觉母题。

### 2.2 表演与采访时长

- 记者和专家主要回答获得10—16秒完整表演区间。
- 长回答允许从人物画面跨接到轨迹图、任务画面或准备蒙太奇。
- 关键任务口令保留通信延迟和动作完成时间。
- 对接、最终下降、第一步、月面起飞、再对接、黑障恢复和着陆期间不安排记者或专家覆盖。

### 2.3 第三视角来源

- 月面便携相机部署前：第三视角统一标注“基于实时遥测的视觉重建”。
- 视觉重建只解释双器距离、下降高度、横移和空间尺度，不承担不可逆事件证明。
- 触月、第一步、再对接和着陆由任务证据机位确认。
- 两名航天员安全落脚并完成相互检查后，部署一台便携月面相机。
- 国旗、科研时间压缩和T+28小时月面起飞由同一台便携月面相机记录。

### 2.4 月面时间线

- 着陆：T+00:00
- 出舱准备完成：T+06:00
- 主舱外活动开始：约T+06:00
- 第一工作点：T+08:20
- 第二工作段：T+10:40—T+12:50
- 主舱外活动结束：T+13:40
- 舱内恢复、样品整理和起飞准备：T+14:00—T+27:30
- 月面起飞：T+28:00

### 2.5 专业说明补齐

- 着陆区解释增加工程可达性与多地质单元集中带来的科学价值。
- 无人探测器同样需要状态检查和载荷初始化；载人任务额外增加人员恢复、穿服、生命保障和舱外程序复核。
- 地月返回约三天内仍需执行轨道修正、姿态与热控、生命保障、人员与样品检查及再入准备。
- 搜救抵达用“时间压缩”字幕处理，不伪装成落地后数秒即开舱。
- 航天员返回后先接受重力再适应评估，再按状态使用支撑座椅或担架转移。

## 3. 对阶段1资产分析的影响

V1.3的100镜映射不得直接作为正式生产映射。V1.3.1需重新执行119镜调用关系，重点新增或校正：

- 梦舟三座满员、两座空置、三座重聚和再入承载四类状态
- 揽月无人对接前状态
- 遥测视觉重建包装及后期角标
- 便携月面相机、月球车前向相机和月球车侧后固定相机
