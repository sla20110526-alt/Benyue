# 阶段2A｜《奔月》中国航天工程设计依据与艺术补全规则 V1.0

建立日期：2026-07-14
适用资产：梦舟舱内、揽月登月舱、工程化国旗展示装置，以及后续相关场景和镜头。
定位：本文件是轻科幻未来纪实推演的美术设计约束，不是任何未公开航天器的官方复原图。

## 1. 设计证据层级

1. 中国载人航天工程、国家航天局等官方公开的任务功能、试验状态与照片。
2. 神舟返回舱、中国空间站等已经公开的人机工程、舱内材料和设备组织语言。
3. 真空、低重力、月尘、热循环、结构载荷、航天服操作等可验证的工程常识。
4. 影视资料只用于摄影可读性、使用痕迹和功能分区的表达方法，不照搬具体航天器构型、标识或国家风格。
5. 公开资料没有覆盖的部分，只允许“为已知任务功能服务”的克制艺术补全；不得写成官方参数或官方设计。

## 2. 共通中国航天设计语言

- 以功能分区、检修可达、束缚固定和手套／失重操作可用为先，不以装饰造型为先。
- 舱内使用暖白／浅灰面板、灰色功能织物、低反光金属、蓝色或少量红色操作识别件；颜色用于分区与安全识别，不做霓虹灯带。
- 设备按面板家族、固定接口、扶手、束缚带和收纳单元组织；允许高密度，但避免无功能的“按钮海洋”。
- 显示器为有限数量的实体屏幕和状态区，保留实体关键控制与手控接口；不使用透明全息屏、巨幅曲面屏或消费电子极简舱。
- 表面允许缝线、紧固点、检修盖、密封件和轻微使用差异；不做军事装甲、豪华客舱或重度末日脏污。
- 所有中文、参数、徽标和国旗图形均后期贴合；AI母图不生成可读文字。

## 3. 梦舟舱内设计锁定方向

### 3.1 事实锚点

- 梦舟承担载人地月往返中的乘员运输与返回任务；具体舱内尚无足以复原完整布局的公开资料。
- 神舟返回舱公开资料把返回舱定义为飞船指挥控制中心，包含仪表显示、报警与照明、导航／姿态／飞行程序／舱内环境信息，以及手动控制和乘员保障设备。
- 中国空间站公开舱内显示出清楚的工作区、生活区、设备区和通道组织；其材料、面板家族、扶手与固定方式可作为“中国航天器舱内语言”参考，但空间站的大体积和失重工作姿态不能直接复制到紧凑返回舱。

### 3.2 艺术补全规则

- 三张承力座椅在舱内始终保持可识别的固定存在，不允许轨道状态把第三张座椅隐藏到地板下或从画面中取消。
- 三张座椅保持统一载荷方向和低矮深度后仰姿态，背面连接同一家族承力框架；不得竖成汽车／客机式高背椅。轨道状态只减少脚端占用，不把整张承力座椅变成壁挂椅。
- 本片采用受约束的“2＋1错位／三角形”艺术布局：两张座椅靠前，第三张后退约半个座椅长度，三座方向一致，不组成横向座椅墙。该布局是本片设计，不宣称官方梦舟方案。
- 舱内转移空间表现为座椅上方、肩部之间和脚端至轴向舱门的三维自由体积，不设计地球建筑式宽阔地板走廊，也不以中央折叠床、担架或平台代替第三张座椅。
- 轴向对接舱门位于锥形舱体前上方轴线顶端，尺度克制；舱门周围由扶手和可见净空组织，不使用占满端舱壁的气闸舱式巨型圆门。
- 指令／显示区集中在前上方斜舱壁，三块有限尺寸实体屏幕和克制实体控制形成一组连续面板；两张靠前座椅外侧可见短手控器，第三张错位座椅不复制完整驾驶台。
- 收纳、生命保障检修盖、通信音频单元、扶手和束缚点沿侧壁紧凑排布，不出现大面积空白墙或松散漂浮物。
- 只继承天和／神舟的功能组织、材料与人机工程语言，不复制其几何布局；梦舟仍应是更紧凑、更高载荷约束、更接近返回舱的空间。
- 窗口数量和面积克制，主要观察依靠小型耐压窗与外部摄像；禁止客机式大窗和观景舱。

### 3.3 本轮修订目标

- V1.0／V1.1及2026-07-15外部回流均不得作为母图继续继承；相关图只保留为失败样本。
- V2.0重新生成：恰好三张低矮后仰承力座椅、2＋1错位关系、锥顶小尺度轴向舱门、座椅上方三维自由体积、紧凑连续控制面板和高密度侧壁必须在同一张母图中可见。
- V2.0只使用“所见即所得”Prompt；工程依据、功能解释、资产登记和艺术补全声明全部放在Prompt正文外。

## 4. 揽月登月舱设计锁定方向

### 4.1 事实锚点

- 官方公开信息显示，揽月由登月舱与推进舱组成，可搭载两名航天员往返环月轨道与月面，并可携带月球车和科学载荷。
- 官方着陆起飞综合验证试验用于验证月面着陆与起飞系统方案、控制方案和触月关机方案；公开试验塔、吊索和伞系统不是飞行构型。
- 本片调用的是推进舱分离后的登月舱：同一飞行器完成着陆、月面驻留、起飞和环月交会对接，四条着陆腿随整器起飞，不采用阿波罗式留月下降级。

### 4.2 艺术补全规则

- 整体为宽扁、低重心、清楚的承力中舱；上部设置对接环和交会敏感器合理安装区，下部形成着陆腿与主推进的结构核心。
- 四条着陆腿大跨距布置，足垫、缓冲支柱、舱体连接点和地面净空相互匹配；不得把腿画成装饰支架。
- 两人舱门、舷梯和扶手形成连续EVA路径；着陆后首级踏步高度、舱门净宽和穿舱外航天服尺度必须可信。
- 外部设备舱分区体现能源、通信、热控、月球车／科学载荷接口和维护边界；细节可艺术补全，但不得把孔口、喷口或箱体写成官方确定结构。
- 主体材料以暖白／浅灰低反光隔热表面、铝合金与石墨灰结构件为主，浅金色多层隔热只在必要区域少量出现。
- 形成中国近未来工程识别的办法是功能组织、比例、面板家族和克制材料，不依赖随机国旗、汉字、红色涂装或科幻装饰。
- 禁止阿波罗登月舱复制、Starship式筒体、飞碟、机翼、巨大舷窗、军用装甲、密集外露管线和无功能天线森林。

### 4.3 本轮修订目标

- V1.0的宽扁低重心、四腿、舱门／舷梯和顶部对接区可以作为构图起点。
- V1.1要减少通用登月器／阿波罗联想，强化一体起降承力关系、载荷接口和中国航天的克制面板语言。

## 5. 工程化国旗展示装置

### 5.1 已知公开约束

- 嫦娥五号完成了中国首次月面国旗独立动态展示；公开资料说明旗面使用国产特殊材料、重量约12克。
- 公开研制报道进一步给出：嫦娥五号展示装置总质量低于1千克，并重点处理月尘卡滞、真空冷焊、轻薄小型运动件和极端环境可靠性。
- 这些信息用于确定材料与机构风险，不直接复制无人探测器上的安装位置或自动展开机构。本片装置是两名航天员可搬运、可展开的未来载人任务艺术设计。

### 5.2 本片锁定方案

- 不采用“普通旗杆插入月壤”的动作。装置由低矮折叠基座、四向展开支臂／宽足垫、可伸缩立杆、上下横向张紧杆、旗面收纳筒和大尺寸锁止手柄组成。
- 基座收纳壳同时作为低位质量块；四个宽足垫带浅防滑纹，只承担稳定与抗滑，不虚构深钻锚固。月面无风，静态主要载荷来自装置自重、旗面张紧和人员操作扰动。
- 立杆与横杆使用真空兼容铰链、限位和锁止；运动副避免裸露精密缝隙，设置防尘罩／刮尘边，材料配对和固体润滑表达需考虑冷焊风险。
- 旗面预折叠于收纳筒，两名航天员完成“放置基座—展开支臂—竖起立杆—拉出横杆与旗面—锁止张紧—退离检查”。手柄、锁扣和握持区必须能被加压手套操作。
- 旗面由上下横杆保持平展，可有极轻微材料弧度和展开后的短时衰减振动；最终静止，不出现风致飘扬或持续波浪。
- BY-PRP-P0-004只验证装置结构；准确五星红旗图形由BY-SYM-P0-001后期贴合，模型不得自由生成星位。
